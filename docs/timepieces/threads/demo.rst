==================================
Demo: Source-Matched Dating Checks
==================================

   *Checking the dating kernel under the model it actually assumes.*

.. figure:: /_static/figures/fig_demo_threads.png
   :width: 100%
   :align: center

   **Threads dating checks.** Panels A and B compare true simulated ages with
   recombination-only MLE and Bayesian point estimates under the segment model.
   Panel C checks calibration after binning by posterior mean. Panel D shows the
   source-matched piecewise-demographic estimator and the production
   high-mutation shortcut.

This figure was generated by running the ``mini_threads`` implementation
on data generated directly from the IBD-segment likelihood and coalescent prior.
It validates the bounded dating kernel; it is not a run of the complete Threads
PBWT/Viterbi/ARG pipeline. The script is at ``figures/fig_demo_threads.py``.
