=========================
Haploid LS HMM Algorithms
=========================

For reference panel :math:`H` with :math:`m` rows and :math:`k` columns, the
forward initialization is

.. math::

   \alpha_j(1)=k^{-1}e_j(s_1).

The recursion uses the rank-one-plus-diagonal identity derived in
:ref:`copying_model`. To avoid underflow, the implementation divides each row
by :math:`c_\ell=\sum_j\widetilde\alpha_j(\ell)`. With normalized previous
row, :math:`S_{\ell-1}=1`, and

.. math::

   \log_{10}P(s\mid H)=\sum_{\ell=1}^m\log_{10}c_\ell.

The backward variable is initialized to one at the final site. The same
transition structure gives

.. math::

   \beta_j(\ell)=\frac{1}{c_{\ell+1}}\left[
   (1-r_{\ell+1})q_j+\frac{r_{\ell+1}}{k}\sum_iq_i\right],

where :math:`q_i=e_i(s_{\ell+1})\beta_i(\ell+1)`. Multiplying scaled forward
and backward rows and renormalizing yields the marginal posterior
:math:`P(Z_\ell=j\mid s,H)`.

Viterbi replaces sums by maxima. For target state :math:`j`, the best
predecessor is either :math:`j` itself or the globally best previous state.
That observation again gives :math:`O(k)` work per site. Posterior decoding
and Viterbi answer different questions: independently maximizing each marginal
posterior need not produce the most probable complete path.

The test suite checks scaled and unscaled likelihood equality, pins forward and
backward arrays generated by lshmm 0.0.8, and verifies Viterbi path scores. For
partial panels, the number of copiable templates can vary by site; a full
implementation must use that site-specific denominator rather than a fixed
panel width.
