=======================================
Demo: Running moments on Simulated Data
=======================================

   *Running mini_moments on simulated genomic data.*

.. figure:: /_static/figures/fig_demo_moments.png
   :width: 100%
   :align: center

   **Mini-moments demo on msprime-simulated data.** Panel A compares simulated
   SFS counts under three histories. Panel B compares the constant-size
   simulation with the analytic neutral :math:`\theta/i` expectation. Panel C
   shows normalized spectra from the mini implementation's neutral demographic
   ODE. Panel D shows Tajima's D for those deterministic expected spectra; it is
   not a sampling distribution or an upstream ``moments`` parity result.

This figure was generated by running the ``mini_moments`` teaching
implementation alongside data simulated with ``msprime``. The script is at
``figures/fig_demo_moments.py``.
