====================================
Demo: Running dadi on Simulated Data
====================================

   *Running mini_dadi on simulated genomic data.*

.. figure:: /_static/figures/fig_demo_dadi.png
   :width: 100%
   :align: center

   **dadi demo on msprime-simulated data.** Panel A: Observed SFS from msprime vs the mini implementation's diffusion approximation. Panel B: Allele frequency density evolution under its dadi-style backward-Euler solver. Panel C: The nonuniform frequency grid. Panel D: SFS predictions under three demographic models.

This figure was generated by running the ``mini_dadi`` implementation
on data simulated with ``msprime``. The script is at
``figures/fig_demo_dadi.py``.

``mini_dadi`` is an independently implemented, neutral one-population teaching
subset. It mirrors the relevant dadi grid, source, flux, and likelihood
conventions; it is not the external dadi package and does not implement dadi's
multi-population, migration, selection, masking, or extrapolation machinery.
